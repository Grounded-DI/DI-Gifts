# DI-Gifts

This repository preserves Logic Runner Lite prompt and GPT setup materials.

## Contents

| Artifact | What it contains |
|---|---|
| [`LogicRunnerLite_GPT_Deploy.md`](LogicRunnerLite_GPT_Deploy.md) | Setup notes for configuring a custom GPT, including a proposed title and description and instructions to upload the prompt file. The document records setup steps; it does not establish that a GPT Store listing was published. |
| [`Logic_Runner_Lite_Explained.md`](Logic_Runner_Lite_Explained.md) | An explanation of a four-stage response flow: input breakdown, logic-tree execution, fixed output structure, and optional entropy dampening. |
| [`logic_runner_lite_prompt.txt`](logic_runner_lite_prompt.txt) | The prompt's four-part response format: input analysis, scrollbound logic chain, deterministic output, and an entropy-resistance note when needed. |

## What the repository demonstrates

The files preserve the intended prompt structure and a corresponding GPT setup procedure. They let a reviewer inspect the requested response format directly.

The repository contains prompt and setup text, not runtime code, test results, or replay evidence. The prompt specifies intended behavior; it does not by itself demonstrate deterministic or drift-free outputs.
